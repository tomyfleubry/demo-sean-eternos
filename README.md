# Sean Eternos

Demo informativa del estudio de tatuajes en Caballito. Sitio estático, sin
formularios, cobros ni sistema de reservas. Los enlaces de consulta apuntan al
contacto del estudio. Incluye `noindex, nofollow`.

## Archivos

`index.html`, `styles.css`, `script.js` y `assets/`. Sin dependencias ni build.

Fotografías y emblema: material propio de Sean Eternos proporcionado para la demo.
No se utilizaron fotos de otros negocios ni imágenes generadas.

Tipografías: Bebas Neue y Manrope, distribuidas bajo SIL Open Font License.
Las licencias se incluyen junto a los archivos tipográficos en `assets/`.
